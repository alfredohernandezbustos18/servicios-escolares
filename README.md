# Servicios Escolares

## Descripción

Proyecto académico para desarrollar un sistema de servicios escolares.

El sistema tiene como objetivo administrar información de estudiantes,
materias, usuarios y calificaciones, utilizando herramientas de
desarrollo y control de versiones.

## Tecnologías

- SQL
- Java
- Git
- GitHub
